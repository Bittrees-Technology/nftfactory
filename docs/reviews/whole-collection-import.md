# Whole-collection import — 2026-09-12

Two explicit modes are available. Collected work verifies wallet ownership as before. Collection mode verifies current owner() or DEFAULT_ADMIN_ROLE on the selected chain before discovery and again before saving each token. Minter and deployer status alone grant nothing. Contract suggestions from paginated wallet NFT inventory and Ethereum/Sepolia deployment history fill the contract field but never grant authority. Factory deployments and granted roles may require a pasted address; suggestion history is not exhaustive. Unsupported explorer networks remain eligible for explicit token IDs if their RPC is supported.

Blank IDs in collection mode enumerate paginated contract instances, not wallet inventory. Every candidate is checked on-chain. ERC-721 imports retain ownerOf(tokenId), retain unknown creator identity, and attribute holdings to the actual owner. ERC-1155 collection imports require totalSupply(id) or exists(id) plus the normal interface check; they do not fabricate an owner or other wallets' balances. Non-enumerable ERC-1155 contracts without existence support remain supported through collected-work mode. Burned or unverifiable items fail individually. Discovery aborts visibly at pagination limits or repeated cursors.

Import mode is saved in the wallet-scoped browser draft. Suggestions, authority evidence and ownership proofs are not restored as valid authentication. Current authority is checked on each import; previous deployer history and cached UI evidence are insufficient. Imported collections have their own collection pages and a separate profile section when Collections is enabled. They are not mixed into the artist's collected holdings.
